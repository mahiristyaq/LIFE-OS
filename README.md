# LIFE OS

A modern, offline-first personal operating system and dashboard designed for academic research, standardized test preparation (IELTS), and daily productivity tracking.

## Features

- **Productivity Command Center:** Real-time focus tracking, task prioritization, and structured daily routines.
- **IELTS Study Hub:** Comprehensive preparation roadmap, band score calculators, and practice resources for Listening, Reading, Writing, and Speaking.
- **Higher Education Matrix:** Comparative planning matrix for international graduate study opportunities and research requirements.
- **Real-Time News Stream:** Curated educational, academic, and technology feeds.
- **Offline-First PWA:** Full Progressive Web App support with service worker caching and zero-dependency local storage.

## Getting Started

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Optionally, install the application as a standalone PWA on desktop or mobile.

## Technology Stack

- HTML5, CSS3 (Modern Glassmorphism Design System)
- Vanilla JavaScript (Offline-First Service Worker, IndexedDB)
- Responsive Grid & Mobile-Optimized Viewport
